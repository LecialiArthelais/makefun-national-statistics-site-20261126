Indonesia in Numbers — a national statistics site for Indonesia: population, GDP, health, education and environment, 2015–2024, from the World Bank, BPS and UNDP. Six pages, hand-rolled SVG charts, a filterable and sortable data table with a CSV download, and a working phone layout — all offline, no network requests, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in a browser.
