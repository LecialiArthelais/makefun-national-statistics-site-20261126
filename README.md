Indonesia in Numbers — a national statistics site for Indonesia: population, GDP, health, education and environment, 2015–2024, from the World Bank, BPS and UNDP. Seven pages, hand-rolled SVG charts, a filterable and sortable data table with a CSV download, and a working phone layout — all offline, no network requests, no build step.

v2 adds: a Regions explorer for all 38 provinces (searchable/sortable table, island tile-map cartogram, compare-any-two tool), a UN World Population Prospects 2024 population pyramid, a rupiah inflation calculator (derived CPI index, 2015–2024), ten more verified indicators (poverty 8.57%, HDI 75.02, BPS inflation 1.57%, tertiary enrolment, mobile/broadband, GDP PPP, imports, trade surplus, maternal mortality), and a source + year on every KPI tile. All 50 indicators are in `app/data.csv`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in a browser.
